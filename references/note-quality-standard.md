# 大学课程笔记制作规范 V1.0

> **此标准仅供参考。** 这是仓库维护者的个人课程笔记要求，不代表浙江大学统一规范，也不默认适用于其他使用者。请按自己的课程、学习目标和偏好取舍。

## 一、总体目标

将教师 PPT、课堂录音、字幕及其他课程材料整理为兼顾**知识体系完整性、概念理解、计算能力和考试复习**的系统性课堂笔记。

笔记应接近一本结构清晰、例题充分、图文结合的学习教材，而不是 PPT 摘要、课堂逐字稿或单纯的知识点清单。

## 二、资料依据

资料优先级：

**教师课件 ＞ 可确认的课堂讲解 ＞ 课堂例题与作业 ＞ 其他参考资料。**

严格区分以下内容：

- 教师明确讲授的概念、公式、例题及结论。
- 根据课程材料整理出来的解释与推导。
- 为帮助理解而自行构造的数据、实例和示意图。

自拟数据必须注明，不得冒充 PPT 原始数据或实际观测结果。字幕出现错别字、遗漏或识别错误时，应结合课件和上下文校验。外部参考资料仅在确有帮助且允许使用时补充，并明确标注来源和补充性质。

## 三、知识组织方式

按照课程实际知识体系建立章节。每个重要知识点尽可能包含：

**概念 → 原理 → 具体例子 → 操作或推导过程 → 结论 → 易错点。**

对于纯定义性内容，不必机械添加例题；对于具有计算、查询、推导、筛选、判断等过程的内容，必须展示完整过程。解释应简洁，但不能因为追求简短而省略关键步骤。

## 四、例题整理标准

每一道实际例题必须能独立阅读和理解，按照以下顺序组织：

1. **题目**：明确要求计算、查询或证明什么。
2. **输入数据**：列出必要的原始表、数值、几何对象或条件。若教师没有提供具体值，可以构造合理示例，并明确标注为自拟数据。
3. **步骤演示**：逐步执行运算，说明每步对数据产生了什么影响。
4. **中间结果**：实际展示被保留、排除、合并、分组或更新的记录。
5. **最终答案**：明确输出，并与原题要求核对。
6. **关键辨析**：只说明容易犯错或影响答案的条件。

不能只写运算符的定义或直接给出最终结果。例如讲解 SQL JOIN 时，应展示输入的两张表、匹配条件、成功与失败的记录，以及最终结果表。

## 五、图示制作标准

图示首先服务于理解，而非美化页面。优先使用与知识相匹配的可视化：

- 集合关系：用具体对象展示交集、并集或差集。
- 数据库查询：展示原始表、条件筛选、中间表和最终表。
- 关系连接：展示记录匹配线、保留与排除的组合及输出关系。
- 全称量词与除运算：展示覆盖矩阵、缺失项检测和反例排除。
- 极值计算：展示逐项比较、非极值淘汰和最终保留对象。
- 空间计算：使用坐标图、几何关系图、缓冲区、拓扑关系或栅格矩阵。
- 系统架构：展示技术结构、数据流、组件职责和调用关系。
- 时间过程：使用时间轴说明状态变化和时段重叠。

过程图尽量呈现：**输入 → 运算 → 中间结果 → 输出**。使用实际名称、数值和记录，避免无意义的 A、B、C 抽象集合。

能直接复用清晰且准确的教师课件原图时优先复用；确需重绘时保留原图的关键逻辑关系。复杂图片只有在能保证结构、标签和关系准确时才重绘；否则用文字、表格或课件页码解释。图片须嵌入对应知识点附近，不能只作为附件或链接。没有实质解释作用的图片不保留，不强求每节课固定使用图片数量。

## 六、公式与代码

- 数学表达式统一采用正确渲染的 LaTeX，不用未经渲染的下标字符串代替公式。
- 公式说明符号含义；涉及推导时保留关键中间步骤。
- SQL、Python 等代码使用对应语言的代码块，保证可以复制、检查与运行。
- 具体示例的输入、运算步骤、图示和最终结果必须相互一致。

## 七、文字详略与版式

- **重要概念**：充分解释定义、适用条件及其与相关概念的区别。
- **实际例题**：以数据表、公式和过程图为主，减少重复的文字解释。
- **复杂架构**：以准确的结构图和组件职责为主。
- **总结复习**：突出知识联系、关键结论与典型错误。

避免大段重复性解释，也不要为了精简把重要知识点压缩成只有一句话。

## 八、Notion 交付与验收

直接更新对应课程、对应课次的原笔记，原则上不新建重复页面。保存后必须回读检查：

1. 章节与课件覆盖范围是否完整。
2. 每道例题是否包含必要的解题步骤和中间结果。
3. 数学公式是否正常渲染，代码块是否完整。
4. 图片是否嵌入相应知识点，而非只有附件或链接。
5. 图中的计算、记录与文字结论是否一致。
6. 是否保留教师原有知识重点、页码和资料来源。
7. 是否存在重复图示、无效内容、未经确认的讲课结论。

若 Notion 工具不支持某项格式或无法嵌入图片，应说明限制，并提供可复制的内容或本地图片文件；不得声称已完成未实际验收的项目。

**最终质量判断：学生不必重新打开 PPT，也能依据笔记理解关键知识，并独立复现课堂例题的解题过程。**
