# 课堂笔记整理提示词模板

请根据我上传的本节课材料，整理一份中文课堂笔记。

## 本节课

- 课程：`<课程名>`
- 日期：`<YYYY-MM-DD>`
- 课次：`<课次或主题>`
- 教师：`<教师；未知则删除此行>`
- 材料：`<逐项列出本次上传的文件名>`

## 整理要求

1. 先提炼本节课的核心问题和知识脉络，再按主题组织内容；不要逐页照抄幻灯片，也不要把不同课次的内容混在一起。
2. 突出关键定义、结论、方法、推导步骤和易错点。重点用简短句子或适度加粗表达，少用装饰性图标。
3. 数学公式使用 `$...$` 行内格式和 `$$...$$` 独立公式格式；检查上下标、符号和变量说明。
4. 代码使用带语言标记的 fenced code block。必要时给出小型、可运行的示例；只有当前环境支持时才要求交互或可视化。
5. 难点可用对照表、步骤表或简洁示意图解释。可以选用少量有助理解的课件图片。复杂图片只有在能忠实还原结构、标注和关系时才重绘；否则用文字、表格或页码引用说明，不要猜图。
6. 以本次上传的课件和字幕为依据。不要补写材料中没有的课堂事实；如需解释背景，单独标为“补充说明”，并说明这是解释而非课堂原文。无法判断时标注“存疑”。
7. 保留重要时间点、页码或来源提示，方便我回到原材料核查。删去口语赘词，但不要改变原意。

## 建议结构

根据实际内容调整，不要为了填满标题而添加空洞段落：

1. 本节主题与核心问题
2. 核心概念与原理
3. 方法、推导或案例
4. 重点结论与易错点

请直接输出整理后的笔记，不要先写改动计划、套话或与本课无关的复习建议。
